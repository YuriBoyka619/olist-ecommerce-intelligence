# Olist E-commerce Intelligence Platform

End-to-end e-commerce analytics and AI capstone project built using Microsoft Fabric, Machine Learning, RAG, Agentic AI, Power BI, and Streamlit.

## Project Components

- Microsoft Fabric Medallion Architecture
- Bronze, Silver, and Gold data layers
- Fabric Warehouse and Semantic Model
- Power BI analytics dashboards
- Machine Learning for late-delivery risk prediction
- Retrieval-Augmented Generation (RAG)
- FAISS vector search
- Gemini LLM
- Agentic AI tools and orchestration
- Streamlit conversational interface
